Cybersecurity Awareness Website

This is a simple Cybersecurity Awareness Website that I created as my part of our Second Semester Field Project.

The main purpose of this webpage is to spread awareness about basic cybersecurity practices and help users understand how they can stay safe while using the internet.

About the Project

Nowadays, we use the internet for many everyday activities such as communication, online payments, social media, education, and storing personal information. Because of this, knowing basic cybersecurity practices has become important.

Through this webpage, I tried to provide useful cybersecurity information in a simple and easy-to-understand way.

The webpage covers basic cybersecurity tips, online safety practices, Do's and Don'ts, and useful cybersecurity resources available for users in India.

Features

* Important cybersecurity safety tips
* Do's and Don'ts for staying safe online
* Information about strong and unique passwords
* Awareness about Two-Factor Authentication (2FA)
* Tips to identify phishing emails and suspicious links
* Safe internet browsing practices
* Tips for protecting personal information and devices
* Helpful cybersecurity resources for users in India
* Link to report cybercrime online
* Simple navigation between different sections
* Clean and easy-to-understand user interface
